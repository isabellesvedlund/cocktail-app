# Cocktail App 🍸

A cocktail catalogue built as an individual front-end project.

The application allows users to browse cocktails, search for drinks, filter by category and view detailed information about individual cocktails.

## Features

- Browse a catalogue of cocktails
- Search for cocktails by name
- Filter cocktails by category
- View cocktail details
- View ingredients and instructions
- Random cocktail feature
- Loading, empty and error states
- Responsive design for mobile and desktop

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- TheCocktailDB API

## API

Cocktail data is fetched from TheCocktailDB:

https://www.thecocktaildb.com/

The API is used to retrieve cocktail information, categories, images, ingredients and instructions.

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```
